    COORDINATE YOUR OWN ACCOUNTS

    Match coordination

    Pair two accounts into a match, record the result, and keep a bounded local ledger. Poolside records what you decide — it does not play or pair anything on the game service. Pairing evidence is judged from the two sessions' own screen readings: a connecting screen says nothing about which match it is connecting to, so two of them are never counted as proof.

    Local records only

    Matches in progress 0

    An account can only be in one match at a time; archiving or removing one cancels its match.

    Add two accounts to coordinate a match.

    Run plan

    Decide in advance how long this run is and what makes it stop, then start it with the two accounts above. A run keeps the same two accounts: while it is in progress, Start match adds the next match to it, and the program stops the run itself when a condition is met. Balance-based stops are not offered, because Poolside has no balance readings. Pause holds the run where it is — the match being played is left alone and nothing new is started, and the time a run spends paused does not count against its plan. Stop run ends the plan and cancels a match it is still holding. When a run ends, both sessions stay open and independent.

    Writes a local JSON record of every run and match this ledger holds — plans, who played, readiness, pairing verdicts and the balances as the sessions reported them. It contains your account names and no passwords, profiles or page text.

    MAKE IT YOUR WORKSPACE

    Settings

    Choose the table label and browser-session defaults for this workspace. Hover the i beside a setting when you want help.

    Workspace preferences

    Choose a default once here. An account can override it later in Account management. Hover an info icon for plain-English help.

    Network location for each account

    Give accounts their own way out to the internet, so each one looks like it is somewhere else. Paste the address your provider gave you — the whole line, exactly as it arrived — name it, save it, then tick the accounts that should use it. An account with no location of its own uses whatever is set above. Ticking a box applies from that account's next load, so close a session before changing where it connects from.

    Advanced (most people never need this)

    Leave these alone unless you know why you need them. "Skip it for" keeps listed addresses off the location — useful for a local printer or a work server, not for the game.

    Recover earlier data

    A copy of the workspace from before its last change is kept beside it, and an interrupted write can leave a staged copy behind. Restoring replaces the accounts you have now with the copy you choose — and the copy in place now is kept first, so the restore itself can be undone by restoring that one.

    Files Poolside has written

    Diagnostics exports and run reports are written to Poolside's own folder on this PC so you can send them on. They are the only files Poolside writes there, and they are the only files this control erases. Browser profiles, saved sessions, the workspace and your accounts are not touched by it.
